# Gestão de Pacientes

Este projeto é dividido em duas partes: a API (Backend) e a interface de usuário (Frontend). Para rodar a aplicação localmente, você precisará abrir **dois terminais** separados.

## 🚀 Como iniciar o projeto

### 1. Iniciando o Backend (Spring Boot)

No seu primeiro terminal, navegue até a pasta do servidor e inicie o Spring Boot com o Maven:

```bash
# Entre na pasta do backend
cd backend

# Inicie a aplicação Spring Boot
mvn spring-boot:run

# Entre na pasta do frontend
cd frontend

# Instale as dependências do projeto (necessário apenas na primeira vez)
npm install

# Inicie a aplicação 
npm run dev
```
